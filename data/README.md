# Input data

`raw/food_access_atlas.csv` is the unchanged Food Access Research Atlas CSV recovered from the uploaded Deepnote project ZIP. `raw/variable_lookup.csv` and `raw/source_notes.csv` accompany that export. The source notes report an initial April 2021 release. Census population/household fields are from 2010; confirm the full source vintage before making claims about current conditions.

Official source provided in the accompanying notes:
https://www.ers.usda.gov/data-products/food-access-research-atlas/download-the-data/

The notebook validates tract identifiers, duplicates, required fields and target values, reports removed rows, and records the CSV SHA-256. The input data are historical and retained here to reproduce this checkpoint.
