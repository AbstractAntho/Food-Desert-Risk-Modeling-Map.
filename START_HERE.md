# Food Access Atlas — analysis checkpoint

1. Extract this ZIP.
2. Open a terminal inside `food-access-atlas`.
3. Create an environment: `python3 -m venv .venv`.
4. Activate it on macOS: `source .venv/bin/activate`.
5. Install dependencies: `python -m pip install -r requirements.txt`.
6. Start Jupyter: `jupyter lab`.
7. Open `notebooks/food_access_analysis.ipynb` and run all cells.

Included: original USDA CSV, variable dictionary, source notes, a consolidated analysis notebook, and results from the executed notebook. Original uploads were not modified.

This is the analysis checkpoint. It does not yet include a rebuilt map, Ollama server, or final project README. Keep the original model results separate from the sensitivity comparison. The final README will use verified outputs after modeling and mapping decisions are complete.
